Negative evidence lowers regional search belief only for newly covered samples; repeated coverage adds no redundant decrease, and the surrogate armchair remains mapped. Consistent unmatched RGB-D observations support a 3D instance track, which is inserted into the scene graph after execution. The route, view footprints, coverage, and memory state are illustrative; the cushion is assumed initially unmapped to demonstrate new-instance insertion.
