# Fig. 8：灰阶矢量重绘稿

对应 `PRE_MAP_VLN/论文/TASE_英文初稿/root.pdf` 中的 Fig. 8，保留局部重试、恢复区域、搜索证据和地图更新四部分内容。此版本为独立图稿。

## 设计

- 尺寸 **184 × 62 mm**，按论文双栏宽度设计。相对于论文中 184 × 90 mm 的旧图减少高度。
- 白底、灰阶几何、细线、统一字体；不使用彩色阶段卡片、家具插画、相机机身、勾叉符号。
- 青绿色仅用于正验证、融合证据和已确认的新实例。颜色之外还有文字、实心/空心标记辅助区分。
- 区域和视点采用正投影几何示意。小圆点为区域采样；视点为空心圆和无填充视场边界。
- (c) 用实心/空心点解释已覆盖样本集合的变化，强调重复覆盖不重复积累负证据。
- (d) 用虚线明确区分执行期间的证据关联和执行后的实例插入。

## 语义范围

图中展示允许自主恢复且最终找到目标的同一任务。一次视点未检出允许本地重试；候选耗尽或局部上限到达后，才在恢复策略允许且存在可行后续搜索的条件下换区。图中未展开预算耗尽等任务级终止出口，也不展示预定义条件任务的激活。

负证据降低搜索区域的信念，不把作为参照的锚点物体删去。只对新覆盖部分积累负证据；重复覆盖不造成额外衰减。这里用定性的“lower belief”表达有效新负证据的通常作用，具体强度、零衰减参数和边界裁剪仍由代码决定。

正验证在执行中解决任务，跨视图的空间一致新检测积累为轨迹，确认的新实例在执行后写入场景图。图中的区域形状、样本数量、视场尺寸、检测位置和图结构都是机制示意，不是实际轨迹、RGB-D 画面、实验测量或概率数值。直线与弧线箭头表示决策或证据流。
