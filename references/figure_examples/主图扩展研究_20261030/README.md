## 研究后保留的三个判断

1. **总览与局部应分工。** FALCON 的长场景总轨迹、局部放大和实拍形成紧凑矩形，比用一个极低俯视角把所有信息压成一条更能兼顾空间感与密度。
2. **观察图应贴近空间证据。** USS-Nav 和 HOV-SG 使观察序列与三维主场景直接关联。本稿可以借鉴相邻的观察列与编号，不照搬房间命名、分层或硬件资源饼图。
3. **三维底图质量是主要瓶颈之一。** ActiveSplat、ConceptGraphs 等图的可读性来自完整表面与清楚的切面，不是配色本身。前几稿反复放大同一张稀疏 RGB-D 点云，增加照片或换颜色并未解决空间观感。

## 已落实的素材变化

在真机归档中找到 `voxel_snapshot/voxel_map.npz` 的实际占用体积，而不是只使用之前的 RGB-D 点云。使用真实占用单元的边界面生成几何模型，以米为单位渲染墙体和家具，并作统一高度裁切来看到内部。

该试验没有根据房间多边形推断墙面，也没有补造地板、建筑或物体。数据来源和显示范围记录于 `our_voxel_geometry_source.json`。图中的记录轨迹仍来自机载 EKF 位姿，位置未重新布局或手绘。
