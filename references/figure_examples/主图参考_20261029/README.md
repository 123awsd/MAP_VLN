## 对上一版的判断

- 平面结构图占据主要面积，但丢失了真实场景的纹理和飞行高度信息。
- 大标题、指令框、图例、四张照片和恢复序列层层分栏，读起来更接近实验汇报。
- 图像权重接近，缺少第一眼能读懂的主要场景。
- 去掉房间文字只能减轻拥挤，无法解决构图本身的问题。

## 已落实到新稿

新稿位于 `../../../figures/source/fig01_real_world/scene_teaser_v3/`（相对论文根目录请直接使用 `figures/source/fig01_real_world/scene_teaser_v3/`）。

- 其余三个任务共用一行照片，任务编号与轨迹位置对应。
- 取消 LogicFly 宣传式标题、分图大标题和完整重复的恢复序列，只保留任务指令的缩写和简短目标标签。

这次研究关注构图与视觉层次，不比较算法性能，也不据图像推断他人的拍摄或标定流程。
