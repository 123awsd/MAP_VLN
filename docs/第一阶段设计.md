# 第一阶段设计与验收

## 数据流

`Habitat RGB-D/Pose → FALCON 几何探索轨迹 → 保存关键帧 → 离线宽词表 OWLv2 + Boxer 3D boxes`

`关键帧 Depth/Pose → 2D 占据栅格 → OccuSG 房间多边形与邻接关系`

`Boxer boxes + OccuSG rooms → 房间语义场景图 JSON`

统一世界坐标采用右手系、Z-up、米制。相机输入采用 optical frame（X 右、Y 下、Z 前）。

## 运行时隔离

- Habitat：`.envs/habitat`，Python 3.9。
- Boxer：`.envs/boxer`，Python 3.12 + PyTorch CUDA。
- FALCON：`pre-map-vln/falcon-noetic:local`，ROS1 Noetic 容器。
- OccuSG：`pre-map-vln/occusg-humble:local`，ROS2 Humble 容器。
- 宿主机全局 Python、ROS、CUDA 和另一个项目均不修改。

## 开发场景验收结果

- HM3D scene：`00861-GLAQ4DNUx5U`。
- FALCON 驱动 Habitat 录制 40 个关键帧，轨迹长度 19.32 m。
- Boxer：163 个候选框；正式高置信融合保留 2 个静态实例，RViz 调试融合保留 26 个实例。
- 占据图：256×321，0.05 m/pixel。
- OccuSG：11 个区域，11 条邻接边，处理耗时 30.4 ms。
- 场景图：11 个房间、2 个物体；识别出 bedroom，其余未知房间等待更完整探索和更丰富物体提示。

## 边界

本结果是公开 HM3D example 上的工程闭环，不是论文级数据集评测。Boxer 物体中心通常位于自由空间多边形之外，因此房间关联先用多边形包含，再用最近多边形边界且限制为 0.75 m；更远物体进入 `unassigned_objects`，不会被静默挂到远处大房间。边界外物体仍可显示，但对房间类别只进行按距离衰减的弱投票。

## RViz 可视化与 bag

项目专用 RViz 配置为 `stage1.rviz`（3D/RGB）和 `stage1_topdown.rviz`（2D 俯视），包含：

- Habitat 第一视角 RGB；
- 3D 窗口使用 `roofless_visualization_node.py`：由无人机高度推断地板面，并按 0.10 m XY 柱的局部最高表面剥离顶棚；固定高度、斜顶和有厚度的顶棚均不再遮挡俯视视线，RViz 地面网格也默认关闭；
- 深蓝细线 `agent_path` 表示 Habitat 实际已执行轨迹，琥珀色 Marker 表示当前 FALCON B-spline 规划，Frontier 保留簇颜色但缩为 1 px 半透明细点；地图由派生节点按 Z 映射为受控的青—蓝—洋红配色，并用 Points 而非大块 Boxes，观感参考 FUEL `office3.gif`。红色命令历史、实时 depth cloud、frontier 标签和候选视点默认关闭；
- 2D 窗口中的占据边界、frontier cells、执行/实际轨迹与机体位置；
- 主窗口和俯视窗口均显示红色相机视锥；视锥订阅 `/uav_simulator/sensor_pose` 的实际光学姿态，以 +Z 为相机前方，不使用规划 yaw；
- Habitat 实际 agent path 与 odometry；
- Boxer 细线框和类别文字；弱透明实体默认关闭，文字可在 RViz namespace 中随时切换。

`roofless_visualization_node.py` 同时用于实时录制和 bag 回放：它直接解析 PointCloud2 的 XYZ 字段，以 NumPy 完成逐柱上包络过滤（不依赖 SciPy），发布 `/pre_map_vln/roofless_map`，并用 de Boor 算法把 `/planning/bspline` 采样为 64 点的 `/pre_map_vln/current_plan`。离地净空、顶棚最小高度和剥离厚度均由 launch 参数配置。Boxer 渐进框来自同回合离线检测结果的时间同步回放；若要求真正在线语义框，需要另行常驻 Boxer 推理进程。

默认包 `outputs/bags/hm3d_stage1_complete_v3_indoor_v1_final.bag` 使用 ROS bag v2 + LZ4，时长 248.303 秒、约 1.7 GB，共 43,332 条消息，RGB 为 2,479 帧。54 类离线词表配置位于 `config/stage1_indoor_v1.txt`；497 个关键帧产生 1,849 个阈值后 OBB，融合为 89 个多视角实例、30 个实际检出类别，并按 71 个 `first_seen` 事件注入。新场景图为 5 rooms + 2 corridors，87 个物体关联到已探索房间、2 个保留为显式未分配。在线第二阶段仍只加载任务图中的少量目标类别。
