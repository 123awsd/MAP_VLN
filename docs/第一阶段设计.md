# 第一阶段设计与验收

## 数据流

`Habitat RGB-D/Pose → FALCON 探索轨迹 → 关键帧 → Boxer 3D boxes`

`关键帧 Depth/Pose → 2D 占据栅格 → OccuSG 房间多边形与邻接关系`

`Boxer boxes + OccuSG rooms → 房间语义场景图 JSON`

统一世界坐标采用右手系、Z-up、米制。相机输入采用 optical frame（X 右、Y 下、Z 前）。

## 运行时隔离

- Habitat：`.envs/habitat`，Python 3.9。
- Boxer：`.envs/boxer`，Python 3.12 + PyTorch CUDA。
- FALCON：`pre-map-vln/falcon-noetic:local`，ROS1 Noetic 容器。
- OccuSG：`pre-map-vln/occusg-humble:local`，ROS2 Humble 容器。
- 宿主机全局 Python、ROS、CUDA 和另一个项目均不修改。

## 开发场景验收结果

- HM3D scene：`00861-GLAQ4DNUx5U`。
- FALCON 驱动 Habitat 录制 40 个关键帧，轨迹长度 19.32 m。
- Boxer：163 个候选框；正式高置信融合保留 2 个静态实例，RViz 调试融合保留 26 个实例。
- 占据图：256×321，0.05 m/pixel。
- OccuSG：11 个区域，11 条邻接边，处理耗时 30.4 ms。
- 场景图：11 个房间、2 个物体；识别出 bedroom，其余未知房间等待更完整探索和更丰富物体提示。

## 边界

本结果是公开 HM3D example 上的工程闭环，不是论文级数据集评测。正式实验仍应在用环境变量安全配置 Matterport 凭据并确认下载范围后，下载 HM3D-Semantics minival 并固定一个多房间家庭场景。Boxer 物体中心通常位于被占据栅格排除的物体/墙面内，因此融合结果会显式记录 `nearest_centroid_fallback`；后续可升级为 3D box footprint 与房间边界的重叠分配。

## RViz 可视化与 bag

项目专用 RViz 配置为 `stage1.rviz`（3D/RGB）和 `stage1_topdown.rviz`（2D 俯视），包含：

- Habitat 第一视角 RGB；
- 3D 窗口使用 `roofless_visualization_node.py` 将 occupied cloud 过滤到 Z=0.50–2.25 m，去掉地板和天花板，只保留墙体/主要障碍物；RViz 地面网格也默认关闭；
- 绿色 `agent_path` 表示 Habitat 实际已执行轨迹，黄色 Marker 表示当前 FALCON B-spline 规划，橙色点表示 Frontier；红色命令历史、实时 depth cloud、frontier 标签和候选视点默认关闭；
- 2D 窗口中的占据边界、frontier cells、执行/实际轨迹与机体位置；
- Habitat 实际 agent path 与 odometry；
- Boxer 细线框；弱透明实体和类别文字保留在 namespace 中但默认关闭。

`roofless_visualization_node.py` 同时用于实时录制和 bag 回放：它以二进制字段过滤方式发布 `/pre_map_vln/roofless_map`，并用 de Boor 算法把 `/planning/bspline` 采样为 64 点的 `/pre_map_vln/current_plan`。高度上下限由 launch 参数配置。Boxer 渐进框来自同回合离线检测结果的时间同步回放；若要求真正在线语义框，需要另行常驻 Boxer 推理进程。

默认包 `outputs/bags/hm3d_stage1_scan_complete_final.bag` 使用 ROS bag v2 + LZ4，时长 39.998 秒，约 182 MB，共 5,560 条消息。RGB 为 400 帧、实测 10.0 Hz；静止超过 0.5 秒后相机以 25°/s 主动扫描，把旧包最长 4.3 秒的重复画面降到最多 0.2 秒。Boxer 使用同回合 80 个关键帧，从 326 个原始框得到 27 个调试实例；可视化注入时排除 2 个距地图超过 0.75 m 的离群框，最终 25 个框按 19 个 `first_seen` 事件渐进显示。原始与融合 CSV 均不删改。
