# 第四阶段：异步开放词表感知、三维融合与失败恢复

更新时间：2026-08-24

## 目标

这一阶段把 OWLv2 从“终点单帧检测器”升级为不阻塞飞行的在线感知模块，并解决三个工程问题：单帧误检不能直接写图、预地图之外的新物体需要多视角确认、一次观察失败不能立即结束任务。

## 在线架构

```text
Habitat RGB-D + pose
    ↓ 非阻塞关键帧提交（忙时丢弃旧请求）
隔离 .envs/boxer 中的常驻 OWLv2 GPU worker
    ↓ 2D box + score
对齐 depth 稳健中值投影
    ↓ 世界坐标 3D box
预地图同类实例 1 m 几何关联 + 多帧空间融合
    ├─ 已有实例：立即更新 track
    └─ 未关联实例：相邻位置至少 2 次观测后才写入 scene graph
```

Habitat 和 Boxer 继续使用各自虚拟环境。`AsyncOpenVocabularyDetector` 只有一个推理线程和一个有界 pending 请求；飞行循环不会等待关键帧检测。终点验证会先 flush 在途结果，再同步取得当前任务证据，避免任务决策漏掉最后一帧。

开发闭环采用每 5 帧尝试提交一次检测。74 帧任务中成功提交并完整回收 9 次，检测忙时丢弃 6 次，没有丢失已提交结果。在线 OWLv2 平均 42.30 ms；完整任务仍为 4 次访问、5.383 m，执行阶段 6.3 s。

## 多帧融合和新物体

已关联的观测按 `associated_object_id` 融合中心、尺寸、最大置信度、首次/末次帧和支持次数。未关联观测按类别与 0.75 m 空间半径聚类，至少两次支持才成为 `online_novel`；单帧候选保留在审计 trace，但不进入 RViz 或 scene graph。

当前真实闭环形成 13 条 track，其中 10 条与预地图实例关联并确认；3 条未关联单帧候选全部被拒绝，因此本回合没有虚构新物体。单元测试另外构造两视角一致的新物体，验证其会写入最近房间并标记 `source=online_owlv2_rgbd_fusion`。

## 多观察位姿失败恢复

每个视觉任务保存已尝试 candidate ID。若检测为 `not_found` 且仍有候选，任务保持 pending，并在下一轮联合规划中排除旧位姿；默认最多尝试 3 个视点。

受控回归把 OWLv2 阈值提高到 0.90，稳定制造检测失败。5 个最终任务都执行了两个不同视点：共 10 visits、5 retries、251 RGB frames、14.94 m。电视第二次仍失败后正确激活 cabinet；所有任务在预算内终止，没有死循环。

## 三地图感知 pilot

从三个真实 HM3D example mesh/navmesh 各固定采样 48 个 RGB 视角，共 144 帧，使用 10 个开放类别。只有 `00861-GLAQ4DNUx5U` 本地带 semantic mesh，因此只有它的 48 帧用于定量 precision/recall；`00337` 和 `00770` 只报告真实 RGB 检测覆盖与速度。

| 指标 | 结果 |
|---|---:|
| 图像数 | 144 |
| OWLv2 平均延迟 | 35.78 ms |
| p95 延迟 | 36.89 ms |
| Semantic-GT micro precision | 0.658 |
| Semantic-GT micro recall | 0.481 |
| Semantic-GT micro F1 | 0.556 |
| chair F1 | 0.857 |
| table F1 | 0.800 |
| bed F1 | 0.727 |
| television F1 | 0.545 |

阈值从 0.20 到 0.60 以 0.025 间隔自动扫描。当前 pilot 的全局最佳 F1 阈值仍为 0.20；类别阈值建议为 bed 0.325、lamp 0.25、television 0.45、shelf 0.425，其余保持 0.20。在线 runner 默认应用这组 pilot 阈值。结果也显示 lamp、cabinet 和 shelf 仍是弱类，不能把五张任务终点全部命中外推成通用高精度。

## 结论边界

- 三地图都是真实 Habitat RGB/几何，不是合成图像。
- 只有 `00861` 有 Semantic GT，另外两图不能用于检测准确率结论。
- 当前指标是 image-level 类别存在性，不是完整 COCO mAP 或 3D IoU。
- 新物体写图路径已实现和测试，但当前真实回合没有两次一致的未知实例，所以新增数量为 0；这是正确拒绝误检，不是伪造 positive case。
- 正式论文仍应在完整 HM3D-Semantics minival 上扩大场景数，并报告类别不均衡置信区间。
