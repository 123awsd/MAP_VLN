# 墙支持轮廓规整试验

基于independent_room_support同一实测输入，对三层统一试验。无GT、房间编号或位置专用规则，原版保留。

本次实际实现的是二维保守轮廓简化，尚非三维墙面重建：以2个栅格（0.10m）容差生成多边形提案，仅允许在已有墙屏障附近删除原边界像素；禁止扩张、填内部孔洞、跨已有墙，保留原连通块数量和0.45m核心。未新增封门或延长墙段规则，不能声称已验证门洞识别。

结果：三层分别删减0.7425、0.7025、0.5775m²，分区数保持7/13/10。无新增标签空间、无墙屏障重叠、连通与核心检查通过。检查不等于语义准确率或小房间完整性验证。

3-05右侧大凸出仍在，仅有局部锯齿改善。本试验不能解决该处室内/外部空间判别及墙线断口问题；未获得足够结构证据前不进一步增大简化容差，也不将其硬裁成矩形。此前“用墙约束规整就能解决”的预期应缩小为局部轮廓改善。
