# 第三阶段：论文级实验协议、基线与消融

更新时间：2026-08-24

## 目标

第三阶段不增加新的演示性模块，而是把第二阶段原型转化为可复现、可比较、可形成论文结论的评测系统。核心问题是：任务重排序、多个观察位姿、真实 A* 代价、终止观察质量和在线条件重规划分别贡献了多少收益。

## 受控任务集

`stage2.benchmark_suite.build_task_suites()` 固定生成四类规范化 task graph：

1. `independent`：5 个独立任务，允许规划器自由重排。
2. `precedence`：包含 lamp → television → cabinet 的必要前置链，door/chair 独立。
3. `conditional`：television 为 found 时跳过 cabinet，not_found 时激活 cabinet；两个分支分别测试。
4. `spatial`：分别要求从 front/left/right/behind 观察目标。

所有任务都经过与 Qwen 输出相同的 schema、DAG、引用和条件校验。评测生成器固定选择每张 navmesh 中可通行面积最大的楼层；语义 anchor 只有在最小观察环上存在自由且 LOS 可见的候选位姿时才会被采样，因此不会把“无解任务”混入成功率统计。

## 实验协议

- 场景：3 个官方 HM3D example 的真实 Habitat navmesh。
- 随机种子：11、23、37。
- 任务情形：independent、precedence、conditional-found、conditional-not_found、spatial。
- 方法：6 种。
- 总实验数：`3 × 3 × 5 × 6 = 270`。
- 几何与 A* 障碍：真实 navmesh。
- 语义目标：受控 synthetic semantic anchors，仅隔离规划行为，不作为语义感知准确率结论。

每个方法在相同场景、seed、task graph、起点和候选集合上运行。规划时间测量前单独清空该方法的 A* cache，在线逐任务重规划期间允许复用自己的 cache，避免方法顺序造成不公平的预热优势。

## 基线与消融

| 方法 | 类别 | 含义 |
|---|---|---|
| `fixed_order_nearest` | baseline | 按语言顺序，每步选择当前 A* 最近候选 |
| `fixed_order_viewpoint` | baseline | 按语言顺序，同时考虑局部观察质量 |
| `task_graph_single_pose` | baseline | 满足 task graph，但每任务只有一个最佳观察位姿 |
| `euclidean_cost` | ablation | 用欧氏距离选择顺序/位姿，再用真实 A* 执行 |
| `no_terminal_quality` | ablation | 保留 task graph、A* 与多个候选，但去掉观察质量项 |
| `joint_astar` | proposed | 联合选择任务顺序和观察位姿，使用真实 A*、飞行时间与观察质量 |

## 代价函数

当前联合目标为：

```text
C = L + 0.25 T + 2.0 C_view
```

其中 `L` 是 A* 水平路径长度。每段 `T` 取水平飞行、垂直升降和 yaw 转向所需时间的最大值：

```text
T_segment = max(L/v_xy, |Δz|/v_z, |Δyaw|/ω_yaw)
```

默认 `v_xy=1.0 m/s`、`v_z=0.5 m/s`、`ω_yaw=1.0 rad/s`。这属于可解释的 2.5D 运动时间近似，不冒充完整 Kinodynamic A* 或 MINCO 控制代价；后续可直接用真实动力学轨迹代价替换该项。

`C_view` 当前由目标观察距离偏差、LOS、观察高度偏差和参照物邻近关系构成。候选 pose 的 yaw 必须面向目标，方向空间约束还会相对目标 box 朝向过滤采样角度。

## 当前结果

270 次实验全部完成，所有方法的 mission success、前置约束满足和条件分支满足率均为 100%。聚合结果由脚本自动写入 `outputs/stage2/paper_benchmark/summary.md`，主要观察如下：

- 完整方法平均路径约 42.97 m，相对固定语言顺序缩短约 26.10%。
- 欧氏代价消融平均约 45.84 m，说明绕障后的真实 A* 代价会改变全局任务顺序/目标位姿选择。
- 单候选 task graph 基线平均约 48.16 m，说明联合选择多个终止观察位姿带来额外路径收益。
- 完整方法的 viewpoint quality 为 0.937，去掉该项的消融为 0.889；它以约 0.34 m 的平均路径增加换取约 5.5% 的相对观察质量提升。该指标目前仍是手工几何 utility，后续需要真实可见面积或学习型 utility 验证。
- Subset-DP + 多候选 A* 的规划时间高于基线，后续需要增加 8–20 任务规模实验，并用分层规划、Beam Search 或 Branch-and-Bound 改善扩展性。

数值以最后一次 `run_stage2_experiments.sh` 输出为准，不手工维护实验表格。

## 指标

每条 trial 记录：

- mission success 与 task completion rate；
- precedence constraint satisfaction；
- conditional branch satisfaction；
- A* executed path length；
- 2.5D estimated flight time 与累计 yaw rotation；
- viewpoint quality 与 LOS visibility rate；
- online replan count；
- 独立 A* cache 条件下的 planning wall time。

报告同时提供总表、按任务类型表和按场景表，原始 trial 保存为 CSV/JSON，便于绘图和统计显著性检验。
