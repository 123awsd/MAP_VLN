# 第六阶段：条件长指令与 VLM 语义恢复搜索

## 目标与边界

本阶段解决“预探索地图中的目标旧位置失效”问题。旧位置未找到时不立即失败，而是执行：

```text
位置内多视角 → Qwen 房间—功能区域先验 → 3D区域实例化
→ 覆盖视点生成 → 语义—几何联合选择 → belief更新与全局重规划
```

Qwen 不做逐帧检测、不生成坐标、不控制飞行器。跨任务物品位置规律学习已冻结。

## 实现

- `stage2/task_graph.py`：任务加入 `search_policy`，支持 `fixed` 与 `semantic_recovery`。
- `stage2/viewpoint_recovery.py`：分别限制总访问次数和单位置视角数；位置耗尽后过滤其余同位置候选。
- `stage2/semantic_recovery.py`：调用 `qwen3.7-plus` 生成最多 3 个房间—功能区域假设，并校验真实房间/物体 ID 与区域类型。
- `stage2/semantic_region_search.py`：将假设实例化为支撑面、地面邻域、家具周围、低视角遮挡区或固定实例；计算区域可见样本、覆盖代价、视点质量和 semantic prior score；基于负观测更新 belief。
- `scripts/run_stage2_habitat.py`：联合 A* 到达代价和区域终端代价动态选点；语义区域耗尽后才加入房间任务 Frontier；发现目标后更新目标实例而不是锚点家具。
- `build_stage2_bag.py`：恢复激活后渐进显示红色旧位置 X、排序候选位置、动态目标框和完整 RGB/真实轨迹。

搜索单元为 `z=(room, semantic_region)`。每个假设记录 `room_id`、`anchor_object_id`、区域类型、关系、high/medium/low 语义优先级、理由和 Qwen provenance。等级映射为 `1.0/0.6/0.3` 的 semantic prior score，不宣称为校准概率。错误引用会被拒绝；没有通过自由空间、LOS、区域可见性和 A* 检查的假设不会执行。

实际顺序不由 Qwen 固定：联合规划器综合 semantic belief、A* 到达代价、区域覆盖代价和观察质量。负观测只按本次新增覆盖比例降权，重复观察同一区域不会重复惩罚；所有语义区域耗尽后才启用低优先级房间 Frontier/NBV。

## 最终六个演示

| Demo | 关键行为 | 结果 |
|---|---|---|
| conditional_01_branch | TV 失败后激活柜子 fallback，椅子可重排 | completed |
| conditional_02_skip | TV found 后跳过架子 fallback | completed |
| conditional_03_parallel | prerequisite + 无序椅子/门 + 条件备用 | completed |
| recovery_01_tv | 柜子旧位置失败，Qwen 搜索电视/架子位置 | Semantic GT found |
| recovery_02_lamp | 架子旧位置失败，Qwen 搜索灯/支撑物 | 受控 found |

受控 stale/found 仅用于确定性演示状态机，在 `verification.controlled_stale_map` 与 `verification.controlled_found` 中明确记录，不计作真实感知准确率。`recovery_01_tv` 的最终电视命中来自 Habitat Semantic GT。

```bash

./scripts/run_final_demos.sh
.envs/habitat/bin/python scripts/validate_final_demos.py
```

回放（`true` 表示循环，完成后不自动退出 RViz）：

```bash

./scripts/replay_stage2_rviz.sh final_demos/recovery_01_tv true 1.0
```

其余名称为 `conditional_02_skip`、`conditional_03_parallel`、`recovery_02_lamp`、`recovery_03_exhausted`。

## 结论边界与下一步

本阶段证明的是恢复闭环、任务状态与几何可执行性，不是大规模语义恢复统计优势。下一步需要在多个带真实语义的 HM3D/MP3D 场景构造位置扰动集，与 Expected-only、Random-room 和 Category-nearest 做配对比较，并报告恢复成功率、搜索路径、候选有效率、感知误差、延迟和置信区间。
