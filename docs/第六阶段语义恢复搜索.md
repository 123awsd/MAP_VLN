# 第六阶段：条件长指令与 VLM 语义恢复搜索

## 目标与边界

本阶段解决“预探索地图中的目标旧位置失效”问题。旧位置未找到时不立即失败，而是执行：

```text
位置内多视角 → Qwen 全局语义假设 → 几何位姿生成 → A* 全局重规划
```

Qwen 不做逐帧检测、不生成坐标、不控制飞行器。跨任务物品位置规律学习已冻结。

## 实现

- `stage2/task_graph.py`：任务加入 `search_policy`，支持 `fixed` 与 `semantic_recovery`。
- `stage2/viewpoint_recovery.py`：分别限制总访问次数和单位置视角数；位置耗尽后过滤其余同位置候选。
- `stage2/semantic_recovery.py`：把全局场景图压缩为房间—物体清单，调用 `qwen3.7-plus` 生成最多 3 个语义位置假设，校验真实房间/物体 ID，再围绕锚点生成几何候选。
- `scripts/run_stage2_habitat.py`：在位置级失败事件上触发一次 VLM 调用，把新候选加入同一 planner，随后继续事件触发式全局规划。
- `build_stage2_bag.py`：恢复激活后渐进显示红色旧位置 X、排序候选位置、动态目标框和完整 RGB/真实轨迹。

每个恢复假设记录 `room_id`、`anchor_object_id`、关系、high/medium/low 语义相关性、理由和 Qwen provenance。错误 ID、错误房间、重复/已失败位置会被拒绝；没有通过自由空间/LOS/A* 检查的假设不会执行。

## 结论边界与下一步

本阶段证明的是恢复闭环、任务状态与几何可执行性，不是大规模语义恢复统计优势。下一步需要在多个带真实语义的 HM3D/MP3D 场景构造位置扰动集，与 Expected-only、Random-room 和 Category-nearest 做配对比较，并报告恢复成功率、搜索路径、候选有效率、感知误差、延迟和置信区间。
