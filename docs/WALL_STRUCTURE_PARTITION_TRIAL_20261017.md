# 墙结构驱动分区：独立算法试验

已实现并运行三层。当前实测效果未通过替换条件，保留上一版。新编号是新空间单元，不对应历史房间编号。

## 核心变化

从实测墙面法向推断主方向，将墙面聚成有限长度的平面投影，并按测量残差建立墙带；共线开口和墙段交接形成显式虚拟边界。先得到边界围成的空间单元，再结合空间观测支持与墙面实际被观察的一侧决定是否接纳。长且缺少墙证据的内部边界合并其两侧单元。未读取旧房间标签、核心、细条裁剪结果作为算法输入；复用的仅为实测观测特征。未使用GT或房间坐标专用规则，无分水岭。

这不是完整三维墙实体重建。当前主方向依赖较强的正交建筑假设；实测法向集中度不足0.9时拒绝强制此模型。开口仍是几何假设，不是已经验证的门。最大开口1.2m、栅格噪声容差及观测多数门槛仍存在，不能称为无参数算法。虚拟边界只用于离线分区，不写入物理地图。

## 验证与结果

受控测试test_wall_structure_cells.py通过：门洞的空气连通性与房间身份分开，长无支持内部线允许合并，实际墙格不被房间占用。实际三层也检查了墙格不重叠。

当前单元数7/13/12。数量接近旧版并不表示效果相同：一楼上部、三楼部分区域漏分，二楼存在额外拆分，部分薄单元仍被接纳。compare.json实际文件为comparison.json，逐旧区域列出被新单元覆盖的比例及重叠ID，仅为变化检查，不是准确率。

目前明确的失败边界是墙结构假设的完整性：墙段缺口会让真实房间连到无界外侧而被排除；把共线但不连续的墙投影贯通又会产生虚假分界。长间隔合并改善过分割，但不能自动区分真实开口、漏测墙及不同高度的投影混合。因此本轮不靠继续裁细条或提高阈值宣布修复。
