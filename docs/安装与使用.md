# 安装与使用

本文面向第一次拿到 PRE_MAP_VLN 的使用者。推荐系统为 Ubuntu 24.04、NVIDIA GPU、可用的 NVIDIA 驱动、Docker 与 NVIDIA Container Toolkit。项目不会修改系统 Python，也不会与同机其他 Conda 项目共用环境。

## 1. 四种安装档位

| 档位 | 用途 | 需要的额外数据 | 当前机器实测体量 |
|---|---|---|---:|
| 源码开发 | 阅读代码、运行单元测试 | Git 仓库 | 很小 |
| 示例 Demo | Habitat example、Boxer、ROS/RViz 回放、6个最终 Demo | 两个 Conda 环境、第三方源码与权重、Docker 镜像、示例场景和精选 bag | 约 20–25GB |
| HM3D7 实验 | 复现 7 场景建图与 70 任务 benchmark | 示例 Demo 的全部内容 + `/shared/PRE_MAP_VLN_hm3d7_v2` | 约 50–60GB |
| 全历史实验 | 再包含旧 MP3D 10场景/100任务和开源基线 | HM3D7 + `/shared/PRE_MAP_VLN_benchmark_v1` + MP3D/基线环境 | 约 160GB 以上 |

旧 MP3D benchmark 当前约 103GB，不建议放进日常迁移包。U盘必须使用 ext4、exFAT 或 NTFS；FAT32 无法保存大于 4GB 的环境包或数据归档。

## 2. 获取代码

联网方式：

```bash
git clone https://github.com/123awsd/MAP_VLN.git PRE_MAP_VLN
cd PRE_MAP_VLN
```

没有网络时，可以提前在有网络的电脑克隆仓库，再把整个 Git 工作目录复制到U盘；不要复制 `.secrets/`。

## 3. 系统依赖

先确认以下命令可用：

```bash
nvidia-smi
docker version
docker compose version
conda --version
```

Docker 必须能够访问 GPU：

```bash
docker run --rm --gpus all nvidia/cuda:13.0.0-base-ubuntu24.04 nvidia-smi
```

宿主机不需要另外安装 ROS1/ROS2；FALCON、RViz 和 OccuSG 的 ROS 依赖由项目 Docker 镜像提供。宿主机至少需要 `git`、`git-lfs`、`curl`、Conda、Docker Engine、Docker Compose 插件和 NVIDIA Container Toolkit。

如果只是阅读代码或运行不依赖仿真的单元测试，可以暂时没有 Docker 和 GPU。

## 4. 联网安装

以下命令均在仓库根目录执行。先拉取已锁定提交的第三方源码：

```bash
./scripts/fetch_dependencies.sh
```

项目使用仓库内的 Conda prefix，不污染 `base` 环境。创建 Habitat 主环境：

```bash
conda create -y -p "$PWD/.envs/habitat" \
  -c conda-forge -c aihabitat \
  python=3.9 cmake=3.27 habitat-sim=0.3.3 withbullet

.envs/habitat/bin/python -m pip install \
  -e third_party/habitat-lab/habitat-lab \
  opencv-python==4.11.0.86 pillow==10.4.0 PyYAML==6.0.3
```

创建本地开放词表检测环境：

```bash
conda create -y -p "$PWD/.envs/boxer" -c conda-forge python=3.12 pip
.envs/boxer/bin/python -m pip install \
  torch==2.13.0 numpy==2.5.2 opencv-python==5.0.0.93 \
  pillow==12.3.0 dill==0.4.1 tqdm==4.70.0

(cd third_party/boxer && bash scripts/download_ckpts.sh)
```

上述 PyTorch 版本对应当前 CUDA 13 机器。如目标机器的驱动或 GPU 不兼容，应按 PyTorch 官方选择器改用与该机器匹配的版本，然后重新执行第 6 节的 GPU 检查。

精确核心版本记录在 `environment.lock.yml`，当前安装快照见 `记忆/环境与版本.md`。`.envs/vlnce_legacy` 仅用于 Open-Nav/VLN-Zero 对比，不属于主系统的必需环境。

构建 ROS1/FALCON 与 ROS2/OccuSG 镜像：

```bash
docker compose build falcon occusg
```

下载无需登录的 HM3D example（包含 Habitat mesh、语义标注和配置）：

```bash
.envs/habitat/bin/python -m habitat_sim.utils.datasets_download \
  --uids hm3d_example --data-path data/
```

该命令会将版本数据放入 `data/versioned_data/hm3d-0.2`，并建立 `data/scene_datasets/hm3d` 链接。若从 U 盘人工恢复，请按第 5 节重建链接。

HM3D train 场景需要 Matterport 研究数据权限。HM3D7 下载凭据必须是 API Token ID 与 Token Secret，而不是网页密码：

```bash
.envs/habitat/bin/python scripts/configure_hm3d_credentials.py
```

Qwen 仅用于 task graph、结构过滤和恢复搜索推理，连续目标检测使用本地 OWLv2。按需配置：

```bash
.envs/habitat/bin/python scripts/configure_secrets.py --qwen-stdin
```

所有凭据保存在 Git 忽略的 `.secrets/`，禁止复制进文档、命令历史、U盘资产包或 Git。

## 5. U盘迁移清单

当前先采用人工拷贝，不制作自动打包脚本。建议在U盘建立下面的目录：

```text
PRE_MAP_VLN_USB/
├── project_assets/
│   ├── third_party/
│   ├── data/versioned_data/hm3d-0.2/
│   ├── checkpoints/                 # 仅开源基线需要
│   └── selected_outputs/            # 只放要展示的bag和结果
├── conda_envs/                      # 后续用conda-pack导出，勿直接压目录
├── docker_images/                   # 后续用docker save导出
└── shared/
    └── PRE_MAP_VLN_hm3d7_v2/       # 复现HM3D7时需要
```

如果新机器能联网，最省空间的方式是只用 Git 获取代码，用官方命令重建环境和下载权重。如果新机器无网，主系统需要拷贝下列项目内资产：

| 源路径 | 内容 | 当前约占用 |
|---|---|---:|
| `third_party/FALCON` | 探索规划源码 | 212MB |
| `third_party/boxer` | Boxer源码及 3 个本地权重 | 1.5GB |
| `third_party/OccuSG` | 房间分割源码 | 620MB |
| `third_party/habitat-lab` | Habitat-Lab固定版本 | 372MB |
| `third_party/Open3D`、`third_party/nlopt` | 构建依赖 | 约140MB |
| `data/versioned_data/hm3d-0.2` | 公开HM3D example | 215MB |

可选资产：

| 源路径 | 何时需要 | 当前约占用 |
|---|---|---:|
| `/shared/PRE_MAP_VLN_hm3d7_v2` | 复现7场景地图/70任务 | 32GB |
| `outputs/bags/hm3d_stage1_complete_v3_indoor_v1_final.bag` | 第一阶段RViz展示 | 1.7GB |
| `outputs/bags/final_demos/` | 六个最终Demo回放 | 1.7GB |
| `outputs/bags/hm3d_stage1_complete_v3_final.bag` | 重建六个最终 Demo 的源 bag | 1.7GB |
| `outputs/scene_graph/` + `runtime/occusg/` | 重建 Demo 的场景图与占据网格 | 约2MB |
| `checkpoints/baselines/opennav` | Open-Nav对比 | 1.2GB |
| `data/scene_datasets/mp3d` | MP3D实验/基线 | 2.2GB |
| `/shared/PRE_MAP_VLN_benchmark_v1` | 旧10场景/100任务全部证据 | 103GB |

不要直接复制 `.envs/` 到不同绝对路径：Conda环境中含有原路径前缀。后续制作正式U盘包时应使用 `conda-pack` 分别导出 Habitat、Boxer 和可选基线环境。两张本地 Docker 镜像约为 4.94GB 和 2.26GB，后续应使用 `docker save/load` 迁移，而不是复制 Docker 系统目录。

默认不拷贝以下内容：

- `.secrets/`：包含个人凭据，必须在目标机重新配置。
- `cache/`：当前约 26GB，主要是可重新下载的 zip、Conda 和 pip 缓存。
- `outputs/` 全目录：只挑选需要展示或对比的 bag/报告。
- `/shared/PRE_MAP_VLN_benchmark_v1`：约 103GB，除非需要旧 MP3D 全量实验证据。

`data/scene_datasets/hm3d` 当前是指向 `data/versioned_data/hm3d-0.2/hm3d` 的绝对链接；换机后需要重建：

```bash
mkdir -p data/scene_datasets
ln -sfn "$PWD/data/versioned_data/hm3d-0.2/hm3d" data/scene_datasets/hm3d
```

共享数据若不放在 `/shared`，运行时指定：

```bash
export PRE_MAP_VLN_BENCHMARK_ROOT=/你的路径/PRE_MAP_VLN_hm3d7_v2
```

## 6. 人工安装检查

```bash
nvidia-smi
docker compose version
docker image inspect pre-map-vln/falcon-noetic:local >/dev/null
docker image inspect pre-map-vln/occusg-humble:local >/dev/null
.envs/habitat/bin/python -c 'import habitat_sim; print(habitat_sim.__version__)'
.envs/boxer/bin/python -c 'import torch; print(torch.__version__, torch.cuda.is_available())'
test -f third_party/boxer/ckpts/owlv2-base-patch16-ensemble.pt
test -f data/scene_datasets/hm3d/example/00861-GLAQ4DNUx5U/GLAQ4DNUx5U.basis.glb
```

以上 `test` 命令无输出且返回码为 0 即表示文件存在。任一项失败时，先补齐环境、权重或场景，不要直接运行完整 benchmark。

## 7. 最短运行路径

运行单元测试：

```bash
.envs/habitat/bin/python -m unittest discover -s tests -v
```

运行 Habitat smoke test：

```bash
.envs/habitat/bin/python scripts/smoke_habitat.py
```

回放第一阶段完整可视化：

```bash
./scripts/replay_bag_rviz.sh hm3d_stage1_complete_v3_indoor_v1_final false 1.0
```

如已从 U 盘恢复最终 Demo bags，可直接回放：

```bash
./scripts/replay_stage2_rviz.sh final_demos/conditional_01_branch true 1.0
./scripts/replay_stage2_rviz.sh final_demos/recovery_01_tv true 1.0
```

重新生成六个最终 Demo（需要场景图、OccuSG 网格、HM3D example 和 `hm3d_stage1_complete_v3_final.bag`）：

```bash
./scripts/run_final_demos.sh
.envs/habitat/bin/python scripts/validate_final_demos.py
```

HM3D7 地图与任务：

```bash
./scripts/start_hm3d7_maps.sh
./scripts/hm3d7_status.sh

# 先人工检查地图和质量报告，再启动任务
./scripts/start_hm3d7_tasks.sh
./scripts/hm3d7_tasks_status.sh
```

回放任一 HM3D7 探索 bag：

```bash
export PRE_MAP_VLN_BENCHMARK_ROOT=/shared/PRE_MAP_VLN_hm3d7_v2
./scripts/replay_benchmark_stage1_rviz.sh 00166-RaYrxWt5pR1 true 1.0
```

参数依次是场景 ID、是否循环和回放倍速。改为 `false 2.0` 表示不循环、2 倍速回放；退出使用 `Ctrl+C`。

## 8. 数据和许可边界

- Git 仓库只保存代码、配置、脚本和小型文档。
- HM3D、MP3D、模型权重和第三方源码分别受其原始许可约束。
- 不要把 HM3D/MP3D 场景、API Token、Qwen Key 或生成的私密数据推到公开仓库。
- U盘迁移仅应在有相应数据访问资格的研究者和设备之间进行；接收者应自行接受数据集协议。
- `/shared` 中的 bag、地图、RGB帧和报告是运行产物，不是项目源码。

## 9. 常见问题

`nvidia-smi` 正常但容器看不到 GPU：检查 NVIDIA Container Toolkit，而不是重装项目环境。

RViz 无法打开：确认当前是图形桌面会话、`DISPLAY` 有值，并运行项目回放脚本生成临时 Xauthority。

HM3D 下载返回 401：使用 API Token ID/Secret；网页邮箱密码和 SDK Public Key 都不能替代。

空间不足：HM3D7 至少预留 70GB，全历史实验建议预留 200GB。运行产物优先放到 `/shared` 或单独数据盘。
