# 房间水平支撑高度分离试验（已回退）

基于899b76b对应的wall_structural_rooms，使用同一700秒实测点云、墙、最终FREE、射线和轨迹。独立输出，不覆盖原版，不使用GT，不按房间编号裁剪。

## 改动

原来相对层高[-0.15,2.85)m内所有|nz|>=0.9水平表面均能独立支持二维房间范围。本版只允许楼面参考±0.15m内的水平点独立提供该支持，保留原0.12m邻近距离；多高度FREE、原射线和轨迹证据不变。之后使用相同种子与分割流程。

这是高度混叠假设的单因素试验，不是完整三维空间判别。楼面参考是既有每层常数；台阶和错层未建模。射线仍使用原宽高度区间。

## 结果

三层分区数仍为7/13/10。可分割范围分别减少2.5025/5.1300/4.0375m²，没有扩大。实际FREE、轨迹和射线保护以及标签不落在墙栅格的断言通过。

305原标签面积5.52m²，原范围内仍有标签5.25m²。显示-X>4.5m的右侧部分原0.6675m²，仍保留0.61m²；其中0.61m²满足既有多高度FREE判据，近地面表面仅支持0.015m²，射线及轨迹均为0。此坐标仅用于结果审计，不参与算法。

因此高处水平表面并不是右侧凸出的唯一保留原因。当前结果不能宣称已解决305，也不能因它看起来像细条而删除真实FREE证据。下一步若继续，应检查三维FREE的高度和墙体分隔关系：空间存在不等于它归属305。

副作用：2-07原2.8425m²保留2.4625m²（减少13.37%），3-04原6.2025m²保留5.035m²（减少18.82%）。这些减少尚无语义GT判定正确，不能以分区数量不变声称未误删。保留试验、不替换原版。

## 用户复核后回退

用户确认缺口过多，撤回试验。两份试验运行/渲染脚本删除；产物移至rejected_height_aware_room_support，仅作失败记录。恢复展示wall_structural_rooms/final_three_floors.png；原版代码与数据从未被覆盖。原新增缺口均来自撤销水平表面支持，不存在原多高度FREE/射线/轨迹支持。305右侧267个旧标签格全部可在标签内部通过四邻域到达原核心，右侧无核心格，房间与墙掩码重叠为0。这支持检查核心扩张的归属规则，而非继续削减观测范围；还不能证明真实三维墙完全封闭此处。
