# 墙端分界约束房间归属：未晋升

基线为899b76b对应wall_structural_rooms，未覆盖。没有重新探索或改变原点云、FREE、观测范围。

试验复用已有墙面方向和墙端几何提出虚拟分界，沿用既有1.2m最大短开口假设；不按305或坐标生成规则。不采用整个拟合平面作为阻挡，拒绝穿过已有核心的分界。在原标签内部按虚拟分界重新计算与核心的四连通；不再连接核心的部分记为未确定，保留观测空间。分界邻接保留房间的一格可继续归属，避免画出人为线孔。

## 验证与结果

受控支路、第二核心保留、无分界时不变三个机制断言通过。三层核心标签不变、无穿墙标签、观测范围保持。分区数仍7/13/10，但数量不变不代表质量不退化。

|层|归属改为待定m²|
|---|---:|
|1|0.3675|
|2|2.1750|
|3|3.5700|

305只有0.0525m²改为待定，主要凸出仍在；206有1.0225m²（原3.1475m²的约32.5%）改为待定，属于明显待核查副作用。因此不替换旧版。

此前全拟合墙面试算穿过大量核心，因此未采用。当前温和分界也没有在305主体与凸出间建立有效隔断。不能为消除形状继续任意增大开口补全长度，不能断言这里已经有完整实测墙而算法穿墙。

这次证据只说明：现有二维墙端几何加核心连接还不能可靠判定305归属。斜顶、矮侧墙与高处表面的三维关系尚未进入分界模型；仅靠任意补线无法证明正确房间边界。保留旧版，后续应先确认该处真实三维边界证据，而不是再缩小整个房间范围。
