# 新机器完整复现

本文档给出两条路线：从 HM3D 开始完整重跑，以及复制轻量 prepared bundle 后直接运行第二阶段。Git 不携带 HM3D、模型权重、Bag、Python 环境、Docker 镜像、API key 和 `outputs/`。

## 1. 系统前提

- Ubuntu、Git、Conda/Miniforge；
- Docker Engine 和 `docker compose`；
- NVIDIA 驱动正常，宿主机 `nvidia-smi` 可用；
- RViz 需要 X11 图形桌面，无桌面可关闭 RViz。

推荐配置 Docker 用户组后重新登录：

~~~bash
sudo usermod -aG docker "$USER"
newgrp docker
docker info
~~~

## 2. Clone 和一键初始化

~~~bash
git clone https://github.com/123awsd/MAP_VLN.git
cd MAP_VLN
./scripts/bootstrap_new_machine.sh --download-boxer-weights
~~~

初始化会按锁文件获取第三方源码，创建 `.envs/habitat`、`.envs/boxer`，下载 Boxer 权重并构建 FALCON/OccuSG 镜像。首次运行需要较长下载和构建时间；两个 Python 环境约 8 GB，Boxer 权重约 1.4 GB，Docker 镜像另占空间。

若本机不适合默认 PyTorch CUDA wheel，可在初始化前设置：

~~~bash
export PRE_MAP_VLN_TORCH_INDEX_URL=https://download.pytorch.org/whl/cu130
export PRE_MAP_VLN_TORCH_VERSION=2.13.0
~~~

## 3. HM3D 和 Qwen

HM3D 按许可证单独取得。训练场景布局应为：

~~~text
<train-root>/00337-CFVBbU9Rsyb/CFVBbU9Rsyb.basis.glb
<hm3d-root>/hm3d_annotated_basis.scene_dataset_config.json
~~~

每个终端设置：

~~~bash
export PRE_MAP_VLN_HM3D_TRAIN_ROOT=/absolute/path/to/hm3d/train
export PRE_MAP_VLN_HM3D_SCENE_CONFIG=/absolute/path/to/hm3d/hm3d_annotated_basis.scene_dataset_config.json
~~~

自然语言任务解析、房间语义和主动恢复使用 Qwen。密钥只写入 Git 忽略目录：

~~~bash
.envs/habitat/bin/python scripts/configure_secrets.py --qwen-stdin
~~~

已有 task graph 时，执行第二阶段本身可以不调用 Qwen。

## 4. 基础验收

~~~bash
./scripts/check_reproducibility.py --scene-id 00337-CFVBbU9Rsyb
.envs/habitat/bin/python -m unittest discover -s tests -v
.envs/habitat/bin/python scripts/smoke_habitat.py \
  --scene-id 00337-CFVBbU9Rsyb
~~~

检查器验证第三方 commit、Python 包、Boxer 权重哈希、Docker 镜像和 HM3D 场景。全部 PASS 后再跑长实验。

## 5A. 最快复现第二阶段

在已经工作的机器上只打包 prepared bundle：

~~~bash
tar -C outputs/stage2_3d/prepared \
  -czf 00337_reference.tar.gz 00337_reference
~~~

复制压缩包到新 clone 后：

~~~bash
mkdir -p outputs/stage2_3d/prepared
tar -C outputs/stage2_3d/prepared \
  -xzf /path/to/00337_reference.tar.gz

./scripts/check_reproducibility.py \
  --scene-id 00337-CFVBbU9Rsyb \
  --prepared 00337_reference
~~~

prepared bundle 只包含全局场景图、FALCON voxel 快照、规划配置和 manifest；仍需本机 HM3D。它不包含大型 Bag、RGB-D episode、Boxer 权重或 API key。

直接运行自然语言任务：

~~~bash
./scripts/run_prepared_stage2.sh \
  00337_reference new_machine_task_v1 \
  "帮我看看二楼厨房台面附近的微波炉、二楼客厅沙发旁的茶几和三楼客厅的电视是不是都还在原位，再顺路确认一下二楼卫生间马桶旁还有没有厕纸，先后顺序你自己安排。" \
  owlv2
~~~

或使用已有任务图，避免调用 Qwen：

~~~bash
./scripts/run_prepared_stage2.sh \
  00337_reference new_machine_task_json \
  config/stage2_tasks/00337_household_multifloor.json owlv2
~~~

## 5B. 从零完整复现

### Stage1 三维探索

先做一分钟无 RViz 冒烟测试：

~~~bash
./scripts/run_hm3d_stage1_3d.sh \
  00337-CFVBbU9Rsyb new_machine_smoke 60 5 5 false compact
~~~

正式运行：

~~~bash
./scripts/prepare_rviz_xauth.sh
./scripts/run_hm3d_stage1_3d.sh \
  00337-CFVBbU9Rsyb full3d_v1 600 5 5 true compact
~~~

`complete` 只表示状态机合法结束；还要检查覆盖率、持续静止/振荡、预测碰撞和 z 范围，不能把超时或手动停止当作探索完成。

### 导出 Bag

~~~bash
RUN=outputs/stage1_3d/00337-CFVBbU9Rsyb/full3d_v1
BAG=outputs/bags/hm3d_stage1_3d_00337_full3d_v1_compact.bag
./scripts/export_stage1_run.sh "$RUN" "$BAG"
~~~

### Boxer 物体框

~~~bash
./scripts/run_boxer_habitat.sh \
  "$RUN/episode" \
  outputs/boxer/00337_full3d_v1 \
  config/stage1_indoor_v2.txt \
  indoor_v2
~~~

### 多楼层房间、楼梯和 Stage2 输入

~~~bash
BOXES=outputs/boxer/00337_full3d_v1/episode/indoor_v2_3dbbs_fused.csv
./scripts/prepare_multifloor_stage2.sh \
  "$RUN" "$BOXES" 00337_reference 3
~~~

该入口依次生成逐层房间输入、几何墙、transition-aware 房间分割、Qwen 房间语义、全局唯一 room/object ID 和不可变 voxel 快照。结果位于：

~~~text
outputs/stage2_3d/prepared/00337_reference/
├── manifest.json
├── scene_graph.json
├── generated_stage1_config.json
└── voxel_snapshot/
~~~

随后按 5A 的 `run_prepared_stage2.sh` 命令运行任务。

## 6. 回放与结果

Stage1 Bag：

~~~bash
./scripts/replay_bag_rviz.sh \
  hm3d_stage1_3d_00337_full3d_v1_compact false 1.0 false
~~~

第二阶段输出位于：

~~~text
outputs/stage2_3d/tasks/<run-name>/
├── task_graph.json
├── run_manifest.json
└── execution/
~~~

脚本拒绝覆盖同名输出；重跑时使用新名称。不要用删除旧结果来掩盖失败原因。

## 7. 哪些内容必须另行复制

- 必须：HM3D；
- 初始化可下载：第三方源码、Boxer 权重；
- 手工重新配置：`.secrets/` 中的 Qwen key；
- 可选：prepared bundle，用于跳过 Stage1/Boxer/房间重建；
- 通常不复制：`.envs/`、Docker 镜像、全量 `outputs/` 和历史 Bag。

提交前始终检查：

~~~bash
git status --short
git diff --check
git -C third_party/FALCON status --short
~~~

自动初始化和运行脚本不会 commit 或 push。
