# 新机器完整复现

本文档用于在另一台 Ubuntu/NVIDIA 电脑上复现当前工程。Git 保存代码、配置、第三方 commit 和 FALCON 补丁；HM3D、模型权重、Bag、Conda 环境与 Docker 镜像不进入 Git。

## 1. 系统前提

- Git、Git LFS（若个人数据仓库使用）、Conda/Miniforge；
- Docker Engine 与 `docker compose`；
- NVIDIA 驱动可用，宿主机 `nvidia-smi` 正常；
- RViz 需要本地图形桌面和 X11，无桌面可用 `RVIZ=false` 运行。

建议将用户加入 Docker 用户组并重新登录：

~~~bash
sudo usermod -aG docker "$USER"
newgrp docker
docker info
~~~

## 2. 克隆并初始化

~~~bash
git clone https://github.com/123awsd/MAP_VLN.git
cd MAP_VLN
./scripts/bootstrap_new_machine.sh --download-boxer-weights
~~~

初始化脚本按 `third_party.lock.yaml` 获取固定源码，创建 `.envs/habitat` 和 `.envs/boxer`，再构建两个 Docker 镜像。它不会下载 HM3D，也不会提交或推送代码。

如果目标 GPU 不适合默认 CUDA 13.0 PyTorch wheel，可先设置：

~~~bash
export PRE_MAP_VLN_TORCH_INDEX_URL=https://download.pytorch.org/whl/cu130
export PRE_MAP_VLN_TORCH_VERSION=2.13.0
./scripts/bootstrap_new_machine.sh --download-boxer-weights
~~~

## 3. 放置 HM3D

训练场景目录应满足：

~~~text
<train-root>/00166-RaYrxWt5pR1/RaYrxWt5pR1.basis.glb
<train-root>/00337-CFVBbU9Rsyb/CFVBbU9Rsyb.basis.glb
...
<hm3d-root>/hm3d_annotated_basis.scene_dataset_config.json
~~~

每个终端设置：

~~~bash
export PRE_MAP_VLN_HM3D_TRAIN_ROOT=/absolute/path/to/hm3d/train
export PRE_MAP_VLN_HM3D_SCENE_CONFIG=/absolute/path/to/hm3d/hm3d_annotated_basis.scene_dataset_config.json
~~~

离线真值对比还需要对应 survey/GLB；真值只用于评估和画图，不进入在线 FALCON 规划。

## 4. 强制验收

~~~bash
./scripts/check_reproducibility.py --scene-id 00166-RaYrxWt5pR1
.envs/habitat/bin/python -m unittest discover -s tests -v
~~~

检查器会验证第三方 commit、Python 版本/关键包、三份 Boxer 权重的 SHA-256、Docker 镜像以及指定 HM3D 场景。全部 PASS 后再运行探索。

## 5. 三维第一阶段

无 RViz 的换机冒烟测试：

~~~bash
./scripts/run_hm3d_stage1_3d.sh \
  00166-RaYrxWt5pR1 new_machine_smoke 60 5 5 false compact
~~~

正式运行：

~~~bash
./scripts/prepare_rviz_xauth.sh
./scripts/run_hm3d_stage1_3d.sh \
  00166-RaYrxWt5pR1 full3d_v1 600 5 5 true compact
~~~

该入口执行可变 z 的三维无人机探索、三维 A*、规划 yaw 和发布前碰撞检查。脚本只在 `run_result.json` 的 termination 为 `complete` 时报告合法完成；仍需结合覆盖率、振荡和预测碰撞日志评价质量。

## 6. 无法由 Git 携带的内容

- HM3D 数据：按数据许可证在新机器下载或从旧机器复制；
- Boxer 三份权重：可由初始化脚本从上游下载；
- 历史 Bag/episode/点云：如需完全复用旧结果，另行复制 `outputs/` 中选定实验；
- `.secrets/`：Qwen 是可选能力，API key 必须在新机器重新配置；
- Docker 镜像和 `.envs/`：推荐按锁定脚本重建，不要直接复制环境目录。

如果只需要继续开发而不复用历史结果，复制 HM3D 后不需要搬运 `outputs/`。
