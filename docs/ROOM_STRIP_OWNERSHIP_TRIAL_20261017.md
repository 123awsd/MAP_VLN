# 房间外细条：归属检查试验

## 共同实现机制

现有wall_guided使用墙表面栅格作为屏障，在支持范围内执行4连通最小最大代价分水岭。房间核心之外，只要有路径绕过墙端/缺口，便可继承房间标签。独立观测证据试验只约束空间是否保留，不能决定该空间属于哪间房。轮廓简化也没有修改这种继承规则。

因此“水平表面/FREE/射线证据 → 保留空间 → 通过缺口连到核心 → 房间着色”可造成墙之间带状区域被旁边房间占用。不能将每条细条都据此认定为墙厚或室外；它们也可能是通道或真实窄支路。

## 本次实现

以independent_room_support为基准，对全部三层每个标签检查与原0.45m核心的直线联系。采样每个核心的边界与最大净空点，四分之一栅格步长检测线段是否全部位于该标签内，并拒绝穿栅格角。缺少联系的像素转成未定型空间，原观测范围和物理地图不变。未使用GT、特定房间或坐标规则。局部窗口仅用于报告效果。

该方法是保守的二维归属启发式，不是三维墙模型或语义分类。采样核心不能证明对所有核心像素都不可见；真实L形窄支路可能转为待定。

## 结果与限制

三层转待定0.275/2.340/2.190m²。3-06上方显示坐标-X(-0.9,2)、Y(9.05,9.4)检查窗，原3-08紫色面积0.325m²，其中0.3175m²（97.7%）转待定。3-04上方也有类似变化。

3-05右侧主体凸出仍在，只有0.2275m²转待定；不能说此处全部解决。2-06原3.2775m²有1.07m²（32.6%）转待定，2-11有0.79m²转待定，必须保留为潜在误伤，不因图形更规整就宣布准确。所有原房间核心保留，但核心保留不等于完整房间保留。

生产检查通过：无新增着色空间、无已有墙屏障重叠、原核心标签不变。受控测试包括开放房间直线成立、墙阻隔直线失败。未修改导航、未启动探索、未commit，未晋升替换。

## 后续：真实栅格连通路径核查

脚本audit_room_strip_connections.py仅追踪已有标签与渲染，不更改分割算法。对3-06上方、3-04上方、2-06右侧各取一个待定点，沿原标签4连通栅格追溯到同标签核心：路径分别3.45m、3.10m、1.45m，墙屏障重叠均为0。直连相同核心端点则分别穿过3、3、1个唯一墙格。最小路径栅格距离变换值为0.05m，不能将其直接当真实通道宽度或机器人可通行性。

图中确有墙分开直接方向，但墙端存在绕行连接。这证明当前生长依赖连通性，会将隔着墙、绕端点相连的空间归入同一标签；不是墙格上直接长出房间色。不能据此证明所有绕墙端区域都是室外，实际内隔墙也会有类似拓扑。

2-06右侧案例的路径也绕内部墙端，故此前32.6%转待定只应称“需要检查的影响范围”，不是已证实误删。当前没有对应语义真值，仍不宣称准确率改进。
