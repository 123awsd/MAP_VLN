- 新增 `stage2/` 核心包：task graph 校验、Qwen VLM 解析、占据栅格 A*、候选终止位姿、Subset-DP 联合规划和动态任务状态机。

- 新增 `parse_stage2_instruction.py`、`plan_stage2_mission.py`、`simulate_stage2_execution.py` 入口和对应单元测试。
- 新增 `run_stage2_habitat.py`：真实 Habitat RGB/Depth/Semantic 执行、终止验证、scene graph 更新和逐任务重规划。
- 新增 `build_stage2_bag.py`、`stage2.rviz`、`stage2_replay.launch` 与 `replay_stage2_rviz.sh`，形成第二阶段完整 RViz/bag 回放。
- 新增 `benchmark_stage2_maps.py`、`run_stage2_multiscene.sh` 和 `validate_stage2.py`，覆盖三地图几何回归与统一自动验收。
- 新增 `run_stage2_demo.sh` 一键全链路入口；新增 `docs/第二阶段设计.md`，同步更新 README 和全部迁移记录。
- task graph 新增 `verification_label`、`on` 关系、缓存读取规范化和失败调用费用入账；候选与规划代码兼容当前 Python 3.9 Habitat 环境。
- 新增 `stage2/benchmark_suite.py`：四类 task suite、六种统一规划方法、动态执行与论文指标。
- 新增 `run_stage2_experiments.py/.sh`：真实 navmesh 多场景多种子 270-trial 实验、JSON/CSV/Markdown 自动汇总。
- `joint_planner.py` 的目标函数增加飞行时间、升降/yaw 约束和尺度更明确的观察质量权重。
- `validate_stage2.py` 增加论文实验的 trial、方法、成功率、A*/Euclidean 和终止质量消融门槛。
- 新增 `tests/test_stage2_benchmark.py` 与 yaw 时间测试；新增 `docs/第三阶段实验评测.md`。
- 新增 `boxer_ext/open_vocab_worker.py` 与 `stage2/open_vocab_detector.py`，形成隔离 Boxer 环境的常驻本地 OWLv2 服务、目标匹配及 RGB-D 世界坐标投影。
- `run_stage2_habitat.py` 默认切换到 OWLv2，支持在线关键帧检测、终点验证、Semantic GT 对照及可选 Qwen fallback。
- 新增开放词表评测/一键运行脚本与 3 个几何/匹配测试；保留 Qwen-VL verifier 作为显式对照实验。
- Stage 2 bag/RViz 新增 `/stage2/open_vocab_boxes`，随在线观测渐进显示本地检测产生的 3D box。

- 修正 Habitat 跟随模式的镜头朝向，新增 body/optical 双姿态语义。
- Boxer MarkerArray 改为持续发布的高亮线框，可视化融合从 2 个扩展到 26 个去重候选。
- RViz 默认降低 occupied cloud 密度/透明度，关闭 depth cloud 和 candidate viewpoints。
- 录制脚本启动前清理明确的瞬时桥文件；回放默认指向最终裁剪 bag。
- 新增 `scripts/record_progressive_stage1.sh` 一键同回合录制/Boxer/注入流程。
- 新增 `scripts/build_progressive_boxes.py`，为融合实例保留首次/末次观测时间和支持数。
- 新增 `inject_progressive_boxes.py`，裁剪 RGB 有效时段并向 bag 注入渐进 MarkerArray。
- 回放 launch 不再将 rosbag player 设为 required，播放完成后 RViz 继续运行。
- 新增静止期主动相机扫描参数，重录 `hm3d_stage1_scan_complete` 完整回合。
- 新增 `stage1_topdown.rviz`，回放默认同时打开 3D/RGB 与 2D 边界/frontier 窗口，并在播放前等待订阅者 2 秒。
- 3D Box 默认只显示更细、更暗的 outline；实体与文字 namespace 默认关闭，agent path 与 FALCON 点状轨迹同步缩细。
- FALCON 镜像增加 `zero_cost_guard.patch`，对当前位置与候选中心数值重合时的 ATSP 边赋极小正值，避免探索进程因 `CHECK_GT` 直接退出。
- 新增 `roofless_visualization_node.py`：二进制过滤 occupied cloud 的地板/天花板，并把当前 B-spline 转成 RViz Marker。
- 主 `stage1.rviz` 改为无地板掀顶视角，加入绿色实际轨迹、黄色当前规划和低透明 Frontier；红色命令历史默认关闭。
- 实时录制与回放 launch 均启动派生可视化节点，且实时入口也可同步打开 2D 俯视 RViz。
- `roofless_visualization_node.py` 改为 odometry 地面估计 + XY 柱局部上包络，支持斜顶和厚顶棚；无新增 Python 依赖。
- `stage1.rviz` 与 `stage1_topdown.rviz` 最终参考 FUEL `office3.gif`：白底、青—蓝—洋红高度细点、深蓝细轨迹、1 px 半透明分类色 Frontier 点簇；移除大块 RGB8 Boxes 的视觉干扰。
- 录制/回放 launch 与 `replay_bag_rviz.sh` 新增 floor-clearance、ceiling-min-height、ceiling-thickness 三个可调参数。
- `roofless_visualization_node.py` 新增 `/pre_map_vln/camera_frustum`，由实际 sensor pose 生成 90°、4:3 红色线框视锥；主/俯视 RViz 默认启用。

- 新增 `/pre_map_vln/styled_box_markers` 显示层：保持渐进 Box 时序，将 outline 调为 0.020 m、RGB 乘 0.72、alpha 至少 0.62；主 RViz 切换到该话题。
