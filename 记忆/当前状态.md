## 下一步

- 任务图后续扩展为 AND–OR 结构：precedence/AND 表示必须完成和先后关系；alternative/OR 表示同一目标的多个位置假设。无固定顺序的假设由路径代价选择先搜索哪个，任一分支 found 即完成目标并取消其他分支，not_found 则排除当前分支后滚动重规划。
- 场景图后续使用三档静态位置稳定性 `high/medium/low`，由 VLM/LLM 根据物体类别、房间和支撑关系给出；不让大模型生成伪精确概率。该档位表示物体跨“预探索快照→任务快照”后仍在原处的常识先验，任务执行期间环境保持静态。
- 位置稳定性采用“VLM 三档先验 + 跨任务经验更新”：同一次任务内的连续帧或多视角不提高稳定档位；每个独立任务回合对一个位置最多贡献一次 `confirmed_same / confirmed_changed / unobserved` 证据。物体跨多个任务一直位于同一位置时，`location_persistence_tier` 可由 low→medium→high；明确移动/缺失时降低。
- 三档必须保留来源：`semantic_prior_tier` 是 VLM 初始化且不可变，`experience_tier` 是跨任务证据学习结果，`effective_tier` 是规划器实际使用档位。`tier_source` 区分 `semantic_prior / experience_upgraded / experience_downgraded / experience_confirmed`，避免把原生 high 与经验升级 high 混为一谈。
- 单次任务期间环境始终静态，长期更新只发生在任务结束后并供下一次任务使用。OR 分支排序综合路径代价、三档位置持久性和任务价值；当前回合的 found/not_found 用于分支剪枝，回合结束再写回长期记忆。

- 获得完整 Matterport token ID/secret 后下载 HM3D-Semantics minival，逐地图运行第一阶段后进行真实语义多场景评测。
- 获得完整 HM3D-Semantics 后扩大 Semantic-GT 场景数，补 COCO-style 2D mAP、3D IoU、距离/遮挡分层和置信区间；当前 144 帧结果只作为 pilot。
- 扩展执行失败恢复和任务规模压力测试，形成论文基线/消融实验；当前课题不扩展动态环境或动态障碍方向。
