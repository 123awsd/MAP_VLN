# 数据接口

## Habitat episode v1

目录包含 `manifest.json` 和 `frame_XXXXXX.npz`。每帧字段：

- `rgb`: H×W×3 uint8
- `depth_m`: H×W float32，米制
- `semantic`: H×W int32
- `position`: 世界系 XYZ，米
- `orientation_xyzw`: optical camera 到世界系的四元数
- `time_ns`: int64

当前相机内参：640×480，fx=fy=320，cx=320，cy=240。

## OccuSG occupancy grid v1

- `*.npy`: H×W int8，ROS OccupancyGrid 行主序；-1 unknown、0 free、100 occupied。
- `*.json`: resolution、origin、width/height、cell 统计和 source episode。
- 世界系为右手 Z-up；二维栅格使用世界 X/Y。

## OccuSG regions v1

`regions.json` 包含 region id、世界系 XY centroid、polygon、convex hull、area 和 adjacent ids。

## Scene graph v1

`outputs/scene_graph/<episode>.json` 包含 rooms、objects、room adjacency edges 和 semantic room type。Boxer 中心处于障碍内部而不落入自由空间多边形时，`room_assignment` 明确记为 `nearest_centroid_fallback`。

## ROS bag 可视化接口

最终 bag：`outputs/bags/hm3d_stage1_progressive_final.bag`。

- `/habitat/rgb`, `/uav_simulator/depth_image`
- `/uav_simulator/odometry`, `/uav_simulator/sensor_pose`
- `/pre_map_vln/agent_path`, `/pre_map_vln/box_markers`
- `/planning/bspline`, `/planning/travel_traj`
- `/planning_vis/frontier` 及 frontier point clouds
- `/voxel_mapping/occupancy_grid_occupied`, `/voxel_mapping/depth_pointcloud`
- `/hgrid/visulization_marker`, `/hgrid/visulization_markerarray`

`orientation_xyzw` 仍表示 optical camera 姿态，供深度建图使用；桥状态中的 `body_orientation_xyzw` 用于 odometry、RViz 机体箭头和 agent path。

`boxer_3dbbs_progressive.csv` 在 Boxer 原字段外增加 `first_seen_ns`、`last_seen_ns` 和 `support_count`。注入后的 `/pre_map_vln/box_markers` 每次发布当前已观测实例的累计 MarkerArray。
