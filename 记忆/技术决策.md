# 技术决策

## TD-001：唯一 Git 根目录

- 决策：只维护 `/home/uav/map_VLN/PRE_MAP_VLN`。
- 原因：隔离另一个项目，便于版本管理和对话迁移。
- 影响：大型数据、环境、权重和第三方源码物理上可位于仓库目录内，但由 `.gitignore` 排除。

## TD-002：多运行时隔离

- Habitat 与 Boxer：项目级 Conda 环境。
- FALCON：Ubuntu 20.04 + ROS Noetic 容器。
- OccuSG：Ubuntu 22.04 + ROS Humble 容器。
- 不在宿主机全局安装 ROS、PCL、Open3D 或替换 CUDA。

## TD-003：场景选择

- 数据集：HM3D-Semantics v0.2 minival。
- 正式实验只固定使用一个多房间、语义丰富、连通性良好的家庭场景。
- 先分析候选场景再确定 scene id。
- 在 token 不可用时，以官方公开 example `00861-GLAQ4DNUx5U` 完成工程闭环，正式评测结论不得由 example 外推。

## TD-004：第三方修改

- 上游源码位于 `third_party/`，由锁文件记录 URL 和 commit。
- 优先在 `src/pre_map_vln/bridges` 编写适配器。
- 必须改上游时将差异保存到 `patches/`。

## TD-005：统一坐标系

- 项目/FALCON 世界系：右手系、Z-up、单位米。
- Habitat `(X右, Y上, -Z前)` 映射到项目 `(X前, Y左, Z上)`。
- 相机数据保存为 optical frame：X 右、Y 下、Z 前，位姿四元数为 XYZW。

## TD-006：资源安全

- OccuSG 构建只允许经 `scripts/build_occusg.sh` 启动。
- 构建前要求至少 12 GiB `MemAvailable` 和 2 GiB `SwapFree`。
- `colcon --parallel-workers 1`，CMake/Make 最多 `-j2`。
- Boxer/Habitat GPU 推理与 C++ 构建不重叠。
- 不清理全局 Docker 容器、镜像或缓存，除非用户明确授权并确认目标。

## TD-007：VLM 是任务约束主入口

- 使用 `qwen3.7-plus` 把自然语言解析成严格 task graph，而不是维护关键词规则作为主方法。
- VLM 输出必须经过 schema、DAG、引用和条件一致性校验；缓存不绕过规范化。
- 导航锚点 `target.label` 与视觉检查目标 `verification_label` 分开表达。
- 所有调用进入费用 ledger，并在 20 元上限前拒绝新请求；密钥只存在 `.secrets/`。

## TD-008：语义—几何联合规划

- 观察位姿由 Boxer 3D box、自由栅格、障碍安全距离、LOS、yaw 和参照物共同生成。
- 路径代价使用栅格 A*；Subset-DP 同时选择满足 precedence 的任务顺序和各任务 candidate pose。
- 每次任务验证后更新 scene graph、应用条件规则并重规划，不把初始 tour 当作静态执行清单。

## TD-009：多场景结论分级

- `00861` 是真实第一阶段 scene graph + Habitat RGB/Semantic 在线闭环。
- `00337/00770` 使用真实 Habitat navmesh，但 synthetic semantic anchors 只验证几何规划泛化。
- 没有完整 Matterport 双字段凭据前，不把 example 几何回归表述为 HM3D minival 的真实语义评测。

## TD-010：评测实例必须先证明可行

- 每个场景固定选择可通行面积最大的 navmesh 楼层，避免随机高度落入楼梯平台或小型楼层连通块。
- synthetic semantic anchor 只有在最小观察环上至少存在一个 free + LOS pose 时才允许进入实验。
- synthetic anchors 仅用于隔离规划算法；正式感知结论必须使用每图真实 Boxer/开放词汇检测结果。

## TD-011：统一代价与公平计时

- 联合目标为 `L + 0.25T + 2.0C_view`。
- `T_segment=max(L/v_xy, |Δz|/v_z, |Δyaw|/ω)`，明确称为 2.5D kinematic time proxy，不称为 Kinodynamic A* 或 MINCO。
- 每种方法开始前清空自己的 A* cache，在线重规划期间允许复用；避免前序方法替后序方法预热造成不公平计时。
- 论文表格全部由原始 JSON trial 自动生成，不手工维护结果数字。
