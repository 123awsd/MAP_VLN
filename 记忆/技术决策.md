# 技术决策

## TD-001：唯一 Git 根目录

- 决策：只维护 `/home/uav/map_VLN/PRE_MAP_VLN`。
- 原因：隔离另一个项目，便于版本管理和对话迁移。
- 影响：大型数据、环境、权重和第三方源码物理上可位于仓库目录内，但由 `.gitignore` 排除。

## TD-002：多运行时隔离

- Habitat 与 Boxer：项目级 Conda 环境。
- FALCON：Ubuntu 20.04 + ROS Noetic 容器。
- OccuSG：Ubuntu 22.04 + ROS Humble 容器。
- 不在宿主机全局安装 ROS、PCL、Open3D 或替换 CUDA。

## TD-003：场景选择

- 数据集：HM3D-Semantics v0.2 minival。
- 正式实验只固定使用一个多房间、语义丰富、连通性良好的家庭场景。
- 先分析候选场景再确定 scene id。
- 在 token 不可用时，以官方公开 example `00861-GLAQ4DNUx5U` 完成工程闭环，正式评测结论不得由 example 外推。

## TD-004：第三方修改

- 上游源码位于 `third_party/`，由锁文件记录 URL 和 commit。
- 优先在 `src/pre_map_vln/bridges` 编写适配器。
- 必须改上游时将差异保存到 `patches/`。

## TD-005：统一坐标系

- 项目/FALCON 世界系：右手系、Z-up、单位米。
- Habitat `(X右, Y上, -Z前)` 映射到项目 `(X前, Y左, Z上)`。
- 相机数据保存为 optical frame：X 右、Y 下、Z 前，位姿四元数为 XYZW。

## TD-006：资源安全

- OccuSG 构建只允许经 `scripts/build_occusg.sh` 启动。
- 构建前要求至少 12 GiB `MemAvailable` 和 2 GiB `SwapFree`。
- `colcon --parallel-workers 1`，CMake/Make 最多 `-j2`。
- Boxer/Habitat GPU 推理与 C++ 构建不重叠。
- 不清理全局 Docker 容器、镜像或缓存，除非用户明确授权并确认目标。
