# 技术决策

## TD-001：唯一 Git 根目录

- 决策：只维护 `/home/uav/map_VLN/PRE_MAP_VLN`。
- 原因：隔离另一个项目，便于版本管理和对话迁移。
- 影响：大型数据、环境、权重和第三方源码物理上可位于仓库目录内，但由 `.gitignore` 排除。

## TD-002：多运行时隔离

- Habitat 与 Boxer：项目级 Conda 环境。
- FALCON：Ubuntu 20.04 + ROS Noetic 容器。
- OccuSG：Ubuntu 22.04 + ROS Humble 容器。
- 不在宿主机全局安装 ROS、PCL、Open3D 或替换 CUDA。

## TD-003：场景选择

- 数据集：HM3D-Semantics v0.2 minival。
- 正式实验只固定使用一个多房间、语义丰富、连通性良好的家庭场景。
- 先分析候选场景再确定 scene id。
