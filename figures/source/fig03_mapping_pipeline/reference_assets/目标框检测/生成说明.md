# 目标框检测生成说明

- 图片：`场景00337_三层目标框_最终版.png`
- 检测数据：`outputs/room_pipeline/00337_dormant_recovery_20260829_boxfloorfix/L1_boxes.csv`、`L2_boxes.csv`、`L3_boxes.csv`
- 楼层轮廓：三层 `L*_wall_grid.npy/json`
- 做法：使用 CSV 中的中心、尺寸和朝向绘制真实定向 3D 长方体；不同目标类别使用浅色系；每层外围使用单格、封闭虚线轮廓。
- 当前参数：层间距 `4.2`，视角 `azimuth=-58`、`elevation=26`，框高缩放 `0.62`，虚线节奏 `7/5`。
- 详细数据源、各层框数量和颜色表见同名 JSON。

需要修改时，优先改同名 JSON 中记录的层间距、视角、框高缩放、透明度或虚线节奏；目标位置不要在 PNG 上手工移动。

## L2 单层图

- 图片：`场景00337_L2_Boxer目标框_单层.png`
- 由 `PRE_MAP_VLN/scripts/render_l2_room_box_standalone.py` 直接读取 L2 原始 CSV，绘制 66 个定向立体框和封闭虚线外轮廓，不是从堆叠图裁剪。
- 视角保持 `azimuth=-58`、`elevation=26`；详细参数见同名 JSON。

## HM3D 原场景 + Boxer 叠加

- 图片：`场景00337_L2_HM3D原场景_Boxer叠加.png`
- 模型：`场景00337_L2_HM3D原场景_Boxer叠加.glb`
- 使用官方 HM3D 00337 的原始纹理网格，裁出 L2 后，将 `L2_boxes.csv` 中 66 个定向框转换到同一 GLB 坐标系并写入模型。
- 框面使用浅色透明材质，边线单独增强；图和 GLB 均由 Blender 脚本生成，没有使用图片生成模型。
- 脚本：`PRE_MAP_VLN/scripts/render_hm3d_l2_cutaway_blender.py`；完整参数见 PNG 同名 JSON。
