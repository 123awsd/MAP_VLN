# 房间分割生成说明

- 推荐图：`场景00337_三层房间语义_浅色柔和阴影版.png`
- 几何来源：`outputs/wall_extraction/00337_dormant_recovery_ceiling_clearance_L1-L3/L*_wall_grid.npy/json`
- 房间语义来源：`outputs/room_pipeline/00337_transition_aware_qwen_v1/L*_scene_graph_qwen.json`
- 做法：将每层房间多边形栅格化并填充浅色，墙体保持灰色，然后按 L1/L2/L3 零厚度堆叠；柔和阴影只用于增强层间关系。
- 堆叠图统一视角：`azimuth=-58`、`elevation=26`。

需要修改时，优先调整房间填充色、透明度、层间距和视角；不要直接在 PNG 上重画房间。房间范围与名称应以各层 `scene_graph_qwen.json` 为准。

`场景00337_三层房间语义_零厚度堆叠_v2.png` 是较早的视觉实验，不作为原始数据版本继续修改。
